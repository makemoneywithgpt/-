# 쿠리만쥬 업무메이트 Next

원작 프레임 기반 동작 구조의 준비 버전입니다. 작업공간에서 확인 가능한 이전 MVP를 기반으로 별도 폴더에 만들었습니다. 완성된 원작 동작 팩은 아직 포함되어 있지 않습니다.

## Windows 실행

표준 CPython 3.12~3.15 x64가 설치된 Windows에서 `run-windows.cmd`를 실행합니다. 의존성은 짧은 사용자별 경로 `%LOCALAPPDATA%\KMate\v`에 설치됩니다. `build-windows.cmd`는 테스트와 리소스 검증 후 `dist\KurimanjuMateNext\KurimanjuMateNext.exe`를 빌드합니다. 배포할 때는 빌드 폴더 전체를 유지합니다. 사용자 설정은 `HKCU\Software\DesktopMate\KurimanjuNext`에 저장됩니다.

- `assets/actions/pack.json`이 있으면 동작 팩을 사용합니다. 우클릭 **애니메이션 테스트**에서 포함된 동작을 직접 재생합니다.
- 기본 대기 상태가 90~180초 이어지면 등록된 특수동작을 순서대로 한 번씩 재생합니다. 동작이 끝나면 기본 대기의 첫 프레임으로 돌아갑니다. 각 PNG는 공통 캔버스에 그려져 전환할 때 창의 배치와 배율이 유지됩니다.
- 팩을 준비하기 전에는 기존 단일 GIF·PNG 재생과 퇴근 카운트다운을 사용할 수 있습니다. 빈 프로그램에는 말풍선과 리소스 선택 안내가 표시됩니다.

## 필요한 원본 자료

| 동작 | 보내줄 원본 |
| --- | --- |
| 기본 대기 | 같은 구도에서 가만히 있는 자세와 눈을 감았다 다시 뜨는 구간. 루프 이음새를 비교할 앞뒤 여유 포함 |
| 음료 마시기 | 마시기 시작부터 미간 찡그리기, 하아 표정까지 이어지는 구간. 마지막 표정의 정지 구간 포함 |
| 졸기 | 눈을 감고 꾸벅한 뒤 눈을 다시 뜨는 구간. 가능하면 시작과 끝의 기본 자세 포함 |

GIF 원본 파일 또는 영상 원본과 사용할 시간 범위를 전달해 주세요. 가능하면 머리와 몸통이 잘리지 않고, 세 동작의 시점과 카메라 배율이 비슷한 구간을 사용합니다. 배경과 캐릭터 경계가 분명한 원본이면 눈·입·미간 주름을 보존하며 마스크를 만들기 쉽습니다. 원본에 없는 단계는 해당 구간의 자료가 필요합니다.

## 제작 및 검수

1. Windows CMD에서 `setup-windows.cmd`를 실행하고 `"%LOCALAPPDATA%\KMate\v\Scripts\python.exe" -m pip install -r requirements-frames.txt`로 제작 도구 의존성을 설치합니다. 아래 예의 `python`은 그 가상환경의 Python입니다.
2. `python -m tools.prepare_frames extract original.gif source-frames`로 합성된 원본 프레임과 프레임별 시간 `frames.json`을 추출합니다. 시간 정보가 0이거나 빠져 있으면 검토한 값으로 `--untimed-ms`를 명시합니다. 영상은 타임스탬프와 함께 추출한 PNG를 같은 레시피에 넣습니다. 가변 프레임률 영상에서는 인접 프레임 타임스탬프의 차이를 사용하고 마지막 프레임 길이도 확인합니다. 영상 디코딩과 마스크 제작은 별도 편집 단계입니다.
3. 배경이 있는 프레임에는 같은 크기의 그레이스케일 PNG 마스크를 준비합니다. 흰색은 유지, 검은색은 제거, 회색은 반투명 가장자리입니다. 기준 자세의 얼굴 중심·몸통을 맞추도록 프레임별 정수 픽셀 이동량을 정합니다. 제작 도구는 마스크 적용과 평행 이동만 수행합니다.
4. 작업 폴더에 아래 형식으로 `recipe.json`을 작성합니다. 예시 숫자와 경로는 형식 설명용입니다. 실제 값은 원본의 프레임별 시간과 정렬에 맞춥니다. 원본이 투명하면 `mask`를 생략할 수 있습니다.

```json
{
  "canvas": [512, 512],
  "clips": {
    "idle": [
      {"file": "source-frames/0001.png", "mask": "masks/0001.png", "offset": [12, 8], "ms": 500}
    ]
  }
}
```

5. `python -m tools.prepare_frames assemble recipe.json prepared-actions`를 실행합니다. 생성된 `pack.json`과 클립 폴더를 `assets/actions/`에 복사합니다. `alignment-report.json`에서 프레임별 전경 좌표, 크기, 시간을 비교합니다. 눈을 감거나 꾸벅하면서 생기는 자연스러운 실루엣 변화는 허용하되, 기준 자세에서 크기가 튀거나 얼굴이 밀리는 프레임은 원본과 대조합니다.
6. `python -m tools.verify_bundle`로 누락 파일, PNG 크기, 알파 여백, 동작별 프레임 수와 총 시간을 확인합니다. Windows 위젯에서 밝고 어두운 배경 위에 가장자리 번짐을 확인하고, 우클릭 메뉴에서 각 동작과 대기 복귀를 테스트합니다. 원본과 번갈아 보면서 눈·입·미간과 정지 구간이 유지되는지 확인합니다. 빌드된 EXE에서 같은 검수를 반복합니다.
