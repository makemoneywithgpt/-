# 쿠리만쥬 업무메이트 3.0 원작 풀뽑기 적용판

첨부된 Go 2.0 소스의 Windows 위젯, 퇴근 카운트다운, 드래그, 크기, 출퇴근·점심시간, 랜덤 행동 빈도·켜기/끄기와 자동실행을 이어받았습니다. 배포 ZIP에는 사용자가 제공한 원본에서 준비한 풀뽑기와 첫 프레임을 사용한 기본 대기가 포함됩니다. 팩이 없으면 카운트다운과 우클릭 메뉴를 사용할 수 있습니다. 기존 합성 캐릭터 프레임과 데모 GIF는 첨부 2.0 ZIP에서 확인할 수 있습니다.

설정은 먼저 기존 `%APPDATA%\KurimanjuMate\settings.json`을 읽을 수 있고, 이 버전의 변경 사항은 별도 `%APPDATA%\KurimanjuMateV3\settings.json`에 저장됩니다. 새 버전을 자동실행으로 등록해도 기존 버전의 등록은 그대로 유지됩니다.

## Windows에서 소스 빌드

Go 1.23 이상이 필요합니다. 명령 프롬프트에서 프로젝트 폴더를 열고 실행하세요.

```bat
go test ./...
go build -trimpath -ldflags="-H windowsgui -s -w" -o KurimanjuMate_v3.exe .
```

배포 ZIP을 받은 경우 압축을 모두 풀고 `KurimanjuMate_v3.exe`를 실행합니다. 우클릭 → **동작 미리보기 → 풀뽑기**에서 원작 동작을 바로 볼 수 있습니다. 동작 팩을 사용할 때는 EXE 옆의 `assets/actions/pack.json`과 그 안에서 참조하는 PNG를 함께 둡니다. 배포 시 EXE와 동작 팩의 상대 위치를 유지하세요. 위젯 실행에는 Python과 관리자 권한이 필요 없습니다.

## 원작 동작 팩 준비

필요한 자료는 GIF 파일 또는 원본 영상과 사용할 타임코드입니다.

| 동작 | 필요한 구간 |
| --- | --- |
| 기본 대기 | 눈 깜빡임이나 원작의 안정된 정지 자세 |
| 해장국 | 쿠리만쥬 해장국.gif |
| 풀뽑기 | 쿠리만쥬 풀뽑기(3).gif |
| 캔 음료 | 쿠리만쥬 술먹방2.gif |
| 레몬 음료 | 쿠리만쥬 술먹방.gif |

캐릭터가 프레임 밖으로 잘리지 않고 동작 간 카메라 구도와 배율이 비슷한 원본이 정렬에 적합합니다. 원본에 없는 동작은 팩에 넣지 않습니다.

1. 제작 도구에는 Python과 Pillow 12.x가 필요합니다. `python -m pip install "Pillow>=12,<13"`로 설치합니다.
2. `python prepare_frames.py extract original.gif source-frames`로 원본의 합성 프레임과 `frames.json`을 추출합니다. 원본의 시간 정보가 0이거나 빠진 프레임은 확인한 값으로 `--untimed-ms`를 명시합니다. 영상에서 가져오는 클립은 타임스탬프와 함께 따로 추출한 PNG를 레시피에 넣고, 인접 타임스탬프의 차이와 마지막 프레임의 노출 시간을 기록합니다.
3. 불투명 배경에는 프레임과 같은 크기의 회색조 PNG 마스크를 준비합니다. 흰색은 유지, 검은색은 제거, 회색은 반투명 경계입니다. 원본에 투명 영역이 있으면 마스크를 생략할 수 있습니다. 레시피에는 기준 자세에 맞춘 픽셀 이동량과 원본 표시 시간을 적습니다. 도구는 프레임을 회전하거나 크기를 개별 변경하지 않습니다.

```json
{
  "canvas": [512, 512],
  "clips": {
    "idle_basic": [
      {"file": "source-frames/0001.png", "mask": "masks/0001.png", "offset": [12, 8], "ms": 500}
    ]
  }
}
```

4. `python prepare_frames.py assemble recipe.json prepared-actions`를 실행합니다. 생성된 `pack.json`과 PNG 경로를 `assets/actions/`에 그대로 복사합니다. `drink_can`, `lemon_drink`, `hangover_soup`, `work_pull`는 원본 구간이 확보되면 같은 방식으로 추가합니다.
5. `alignment-report.json`의 프레임별 전경 좌표, 크기, 시간을 원본과 비교합니다. 위젯 시작 시에도 누락 파일, 캔버스 크기, 시간 값, 투명 여백을 검사합니다. 문제가 있으면 **우클릭 → 동작 팩 상태**에서 확인할 수 있습니다.

## Windows 위젯 검수

- **우클릭 → 동작 미리보기**로 팩에 들어 있는 동작을 각각 실행합니다. 특수동작이 한 번 끝난 뒤 기본 대기 첫 프레임으로 돌아오는지, 전환 중 위젯 위치와 배율이 유지되는지 확인합니다.
- 밝은 배경과 어두운 배경 위에서 가장자리를 확인합니다. 원본과 번갈아 보며 눈·입·미간, 비율, 각 프레임의 정지 시간을 비교합니다.
- 랜덤 행동 빈도를 바꾸어 자동 전환과 조용한 모드를 확인합니다. 특수동작 중에도 카운트다운 숫자가 계속 갱신되는지 확인합니다.


## 3.0 동작과 검증 상태

자동 이벤트는 설정에 따라 20~60초 간격을 사용합니다. 설정된 근무·점심 시간, 월요일 오전, 퇴근 전후에 따라 후보가 달라집니다. 직전 특수동작은 자동 후보에서 제외합니다. 후보가 한 개뿐이면 한 번의 대기 간격을 더 둔 뒤 다시 재생할 수 있습니다. 클릭이나 미리보기 요청은 재생 중인 동작이 끝나고 잠깐 대기한 뒤 처리합니다. 특수동작은 한 번 재생합니다.

`python prepare_frames.py compare source-frames prepared-actions drink_can review-can`으로 프레임 시간 일치 여부와 밝고 어두운 배경에서의 비교 시트를 만들 수 있습니다. 이 도구는 프레임 수나 표시 시간이 달라지면 실패합니다. 상세 배포 상태는 [검증 보고서](VERIFICATION.md)를 참고하세요.

배포 ZIP의 `review/`에는 풀뽑기 비교 GIF와 네 동작의 비교 시트가 들어 있습니다. `tools/review_originals.py`는 이번 마스크와 비교 자료를 원본 파일 폴더에서 다시 만드는 제작용 도구이며 Pillow, NumPy, OpenCV가 필요합니다.
