# 쿠리만쥬 데스크톱 펫 3.1 테스트 빌드

압축을 전부 풀고 Windows 10/11 x64에서 `KurimanjuMate_v31.exe`를 실행합니다. EXE 옆 `assets/actions/` 경로를 유지하세요. 위젯 실행에는 Python과 관리자 권한이 필요 없습니다.

- **우클릭 → 동작 미리보기 → 풀뽑기**에서 한 번 재생합니다.
- **우클릭 → 동작 미리보기 → 풀뽑기 5초 간격 테스트**를 켜면 기본 대기에서 약 5초 후 풀뽑기를 재생하고, 돌아온 뒤 다시 5초를 셉니다. 이 테스트는 시간대와 랜덤 행동 설정을 무시합니다. 다시 선택하면 종료되며 재시작 시 기본값은 꺼짐입니다.
- 일반 자동 동작은 랜덤 행동을 켜고, 업무 시간대에 설정된 간격이 지나면 실행합니다. 출근 직후·점심·퇴근 직전처럼 풀뽑기 자격이 없는 시간대는 **우클릭 → 자동 동작 진단**에서 현재 상태, 다음 확인 시각 및 대기 사유를 확인할 수 있습니다.
- 정면 원본 URL은 클라우드 프록시 HTTP 403으로 확보하지 못했습니다. 현재 기본 대기는 말풍선만 표시합니다. 바로잡은 풀뽑기 첫 프레임은 특수동작에서만 사용합니다.

3.1 설정은 `%APPDATA%\KurimanjuMateV31\settings.json`에 별도로 저장합니다. 처음에는 기존 3.0 설정을 읽습니다. 자동실행 등록도 3.1과 3.0이 각각 별도입니다.

## 정면 대기 이미지 준비

제공된 원본에서 배경만 분리하고, 리뷰한 투명 PNG를 `assets/actions/idle_basic.png`로 둡니다. 프레임 캔버스는 풀뽑기와 동일한 210×226이며 사방에 투명 여백이 필요합니다. 프로그램은 이 한 장을 정지 자세로 표시합니다. 팩의 `clips`에는 특수동작만 넣습니다.

제작용 `prepare_frames.py assemble`은 레시피에서 단일 `idle_basic` 이미지를 별도 PNG로 내보냅니다. 배경 마스크를 지정할 수 있고, 크롭과 픽셀 이동량을 원본에 맞춰 검토해야 합니다. `tools/review_originals.py`로 풀뽑기 마스크를 재생성하려면 Pillow, NumPy, OpenCV와 업로드한 원본 GIF가 필요합니다.

## 빌드 및 검증

Go 1.23 이상으로 프로젝트 폴더에서 실행합니다.

```bat
go test ./...
go build -trimpath -ldflags="-H windowsgui -s -w" -o KurimanjuMate_v31.exe .
```

[검증 기록](VERIFICATION.md)과 배포 ZIP의 `review/`에서 원본·3.0·3.1 비교를 확인할 수 있습니다.
