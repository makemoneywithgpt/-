# Issue #1 설계 및 검증 계획

기존 `market_data`를 수정하지 않고 로컬 파일만 읽는 `backtesting` 패키지를 추가한다.
`data.py`: UTC·시간 범위·완료 봉·OHLCV 검증, 누락 구간 오류.
`strategy.py`: 과거/현재 완료 봉만 받는 전략 인터페이스와 SMA 교차 예제.
`engine.py`: 다음 시가 가상 체결, 단일 포지션, 위험 예산·1배 한도,
손절/익절·갭·72시간 한도·마지막 봉 청산, 시간별 평가자산.
`report.py`, `cli.py`: 독립 종목별 CSV/JSON 보고서와 Windows 명령.
외부 서비스 호출, 계좌, API 키, 실제 주문 기능은 포함하지 않는다.

먼저 합성 데이터 테스트를 작성한다. 신호 시점/과거 접두 구간 불변성,
다음 시가 체결, 양쪽 비용, 수량 상한과 위험 예산, 72시간, 롱/숏 갭,
동시 터치 손절 우선, 누락/중복/비정상/미완료 봉, 결정론적 결과,
보고서 수치와 CLI 성공/실패, 기존 수집기 회귀를 확인한다.
실제 Windows 데이터 전체 백테스트나 검증되지 않은 성과는 주장하지 않는다.

## 검증 결과

- Python 3.12, 최신 main의 NumPy 2.5.4 / pandas 3.1.0 / PyArrow 26.0.1 설치 후
  `python -m pytest -q`: 55 passed (백테스팅 41 + 기존 수집기 14).
- 기존 설치 명령 `pip install -e ".[test]"` 및 `pip check` 통과.
- 합성 데이터로 CLI 성공/오류, CSV/JSON, 재현성 및 독립 종목 처리를 확인.
- 사용자 Windows 원본 데이터, 실제 성과, Windows/Python 3.15 실행은 미검증.
- API 키/계좌/실제 주문 코드는 없으며, 원시 시장 데이터는 커밋에 포함하지 않는다.
